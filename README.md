## About the Course

- **Course:** Abstract Algebra, Harvard Mathematics 122 / Extension School Math E-222
- **Instructor:** [Benedict Gross](https://people.math.harvard.edu/~gross/)
- **Institution:** Harvard University, with the lectures offered online through Harvard Extension School
- **Original offering:** Fall 2003
- **Course text:** Michael Artin, *Algebra*
- **Lecture format:** A progression from familiar linear algebra and matrix examples to abstract algebraic structures and their applications

The course develops abstract algebra through several interconnected themes:

- groups, subgroups, cyclic groups, and permutation groups;
- homomorphisms, kernels, normal subgroups, cosets, and quotient groups;
- Lagrange's theorem and the isomorphism theorem;
- fields, finite fields, and vector spaces over arbitrary fields;
- bases, dimension, direct sums, and quotient spaces;
- linear transformations, matrix representations, and change of basis;
- rank–nullity, invariant subspaces, eigenvalues, and characteristic polynomials.

The original course materials and historical syllabus are linked from [Professor Gross's Harvard page](https://people.math.harvard.edu/~gross/).

## Conventions

- Groups are written multiplicatively unless an additive operation is more natural.
- $`H\leq G`$ means that $`H`$ is a subgroup of $`G`$.
- $`H\trianglelefteq G`$ means that $`H`$ is a normal subgroup of $`G`$.
- $`\mathbb{F}_p`$ denotes the field with $`p`$ elements for prime $`p`$.
- Displayed mathematics uses LaTeX syntax supported by GitHub Markdown.

Corrections and improvements are welcome.
