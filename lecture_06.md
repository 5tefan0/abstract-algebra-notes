# Lecture 6 — Modular Arithmetic and Quotient Groups (Preview)

## 1. Motivation: Arithmetic of Evens and Odds

A familiar example from elementary school: integers can be partitioned into **even** and **odd** numbers, and there is a consistent arithmetic on these classes:

| $+$ | even | odd |
|---|---|---|
| even | even | odd |
| odd | odd | even |

| $\times$ | even | odd |
|---|---|---|
| even | even | even |
| odd | even | odd |

This works because $2 \mid (a - b)$ and $2 \mid (c - d)$ imply $2 \mid ((a+c) - (b+d))$ and $2 \mid (ac - bd)$. The goal of this lecture is to generalize from $n = 2$ to arbitrary positive integers $n$.

## 2. Congruence Modulo $n$

**Definition.** Fix a positive integer $n$. For integers $a, b \in \mathbb{Z}$, we say $a$ is **congruent to $b$ modulo $n$**, written

```math
a \equiv b \pmod{n},
```

if $n \mid (a - b)$, i.e., $a - b \in n\mathbb{Z}$.

**This is an equivalence relation:**
1. **Reflexive:** $a - a = 0 \in n\mathbb{Z}$. ✓
2. **Symmetric:** $n \mid (a-b) \implies n \mid (b-a)$. ✓
3. **Transitive:** $n \mid (a-b)$ and $n \mid (b-c) \implies n \mid (a-c)$ (since $(a-c) = (a-b)+(b-c)$). ✓

## 3. The Equivalence Classes

The equivalence class of $a$ under this relation is the **residue class**

```math
\bar{a} = a + n\mathbb{Z} = \{ a + kn : k \in \mathbb{Z} \}.
```

This is precisely the **left coset** of the subgroup $n\mathbb{Z} \leq \mathbb{Z}$ containing $a$ (in additive notation, cosets are written $a + H$).

**The distinct residue classes modulo $n$ are exactly $\bar{0}, \bar{1}, \bar{2}, \ldots, \overline{n-1}$.**

*Proof.* By the division algorithm, any integer $a$ can be written $a = qn + r$ with $0 \leq r < n$, giving $\bar{a} = \bar{r}$. Furthermore, if $0 \leq r, r' < n$ and $\bar{r} = \bar{r'}$, then $n \mid (r - r')$; since $|r - r'| < n$, we need $r = r'$. So these $n$ classes are distinct. $\square$

## 4. The Group $\mathbb{Z}/n\mathbb{Z}$

**Definition.** The **integers modulo $n$** is the set

```math
\mathbb{Z}/n\mathbb{Z} = \{ \bar{0}, \bar{1}, \bar{2}, \ldots, \overline{n-1} \}
```

with **addition** defined by

```math
\bar{a} + \bar{b} = \overline{a + b}.
```

**This is well-defined:** if $\bar{a} = \bar{a'}$ and $\bar{b} = \bar{b'}$, then $n \mid (a - a')$ and $n \mid (b - b')$, so $n \mid ((a+b) - (a'+b'))$, giving $\overline{a+b} = \overline{a'+b'}$.

**$(\mathbb{Z}/n\mathbb{Z}, +)$ is an abelian group:**
- **Associativity:** $(\bar{a} + \bar{b}) + \bar{c} = \overline{(a+b)+c} = \overline{a+(b+c)} = \bar{a} + (\bar{b} + \bar{c})$ (inherited from $\mathbb{Z}$).
- **Identity:** $\bar{0}$, since $\bar{0} + \bar{a} = \bar{a}$.
- **Inverses:** $-\bar{a} = \overline{-a} = \overline{n - a}$.
- **Commutativity:** $\bar{a} + \bar{b} = \overline{a+b} = \overline{b+a} = \bar{b} + \bar{a}$.

**$\mathbb{Z}/n\mathbb{Z}$ is cyclic of order $n$**, generated by $\bar{1}$:

```math
\bar{1} + \bar{1} + \cdots + \bar{1}\ (k \text{ times}) = \bar{k},
```

so $\bar{1}$ generates all of $\mathbb{Z}/n\mathbb{Z}$. Adding $\bar{1}$ to itself $n$ times gives $\bar{n} = \bar{0}$, so $\mathrm{ord}(\bar{1}) = n$.

The natural map $\pi: \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$, $a \mapsto \bar{a}$ is a **surjective group homomorphism** with $\ker(\pi) = n\mathbb{Z}$.

## 5. Multiplication in $\mathbb{Z}/n\mathbb{Z}$

Define **multiplication** by

```math
\bar{a} \cdot \bar{b} = \overline{ab}.
```

**Well-defined:** if $n \mid (a - a')$ and $n \mid (b - b')$, then $ab - a'b' = a(b - b') + b'(a - a')$, so $n \mid (ab - a'b')$.

**Distributive law:** $\bar{a}(\bar{b} + \bar{c}) = \overline{a(b+c)} = \overline{ab + ac} = \bar{a}\bar{b} + \bar{a}\bar{c}$.

So $\mathbb{Z}/n\mathbb{Z}$ is a **ring** — a set that is an abelian group under addition and has an associative multiplication with identity $\bar{1}$ that distributes over addition. (We will study rings in depth later.)

## 6. Units: The Group $(\mathbb{Z}/n\mathbb{Z})^\times$

Not every element of $\mathbb{Z}/n\mathbb{Z}$ has a multiplicative inverse. For example, $\bar{0}$ has no inverse since $\bar{0} \cdot \bar{c} = \bar{0} \neq \bar{1}$ for all $\bar{c}$.

**Definition.** The group of **units** (or **multiplicative group**) of $\mathbb{Z}/n\mathbb{Z}$ is

```math
(\mathbb{Z}/n\mathbb{Z})^\times = \{ \bar{a} \in \mathbb{Z}/n\mathbb{Z} : \exists\, \bar{c}\ \text{with}\ \bar{a}\bar{c} = \bar{1} \}.
```

This is a group under multiplication.

### GCD and Bézout's Lemma

**Definition.** The **greatest common divisor** $\gcd(m, n)$ of integers $m, n$ (not both zero) is the unique positive integer $d$ such that:
- $d \mid m$ and $d \mid n$,
- if $e \mid m$ and $e \mid n$, then $e \mid d$.

**Key Lemma (Bézout's Identity).**

```math
m\mathbb{Z} + n\mathbb{Z} = \gcd(m, n)\mathbb{Z}.
```

*Proof.* The set $m\mathbb{Z} + n\mathbb{Z} = \{mr + ns : r, s \in \mathbb{Z}\}$ is a subgroup of $\mathbb{Z}$, so it equals $d\mathbb{Z}$ for some positive integer $d$ (by the classification of subgroups of $\mathbb{Z}$). Since $m = m \cdot 1 + n \cdot 0 \in m\mathbb{Z} + n\mathbb{Z} = d\mathbb{Z}$, we get $d \mid m$; similarly $d \mid n$. Conversely, $d \in d\mathbb{Z} = m\mathbb{Z} + n\mathbb{Z}$, so $d = mr + ns$ for some $r, s$; if $e \mid m$ and $e \mid n$ then $e \mid d$. This is exactly the characterization of $\gcd(m, n)$, so $d = \gcd(m, n)$. $\square$

In particular, **Bézout**: $\gcd(a, n) = 1 \iff \exists\, r, s \in \mathbb{Z}$ with $ar + ns = 1$.

### Structure of $(\mathbb{Z}/n\mathbb{Z})^\times$

**Theorem.** $\bar{a} \in (\mathbb{Z}/n\mathbb{Z})^\times$ if and only if $\gcd(a, n) = 1$.

**Proof.**

$(\Rightarrow)$: Suppose $\gcd(a, n) = 1$. By Bézout, $\exists\, r, s$ with $ar + ns = 1$, so $ar \equiv 1 \pmod{n}$, i.e., $\bar{a} \cdot \bar{r} = \bar{1}$. Thus $\bar{a}$ is a unit.

$(\Leftarrow)$: Suppose $\bar{a}\bar{c} = \bar{1}$, i.e., $ac - 1 = nb$ for some $b \in \mathbb{Z}$, i.e., $ac + n(-b) = 1$. So $1 \in a\mathbb{Z} + n\mathbb{Z} = \gcd(a,n)\mathbb{Z}$, which forces $\gcd(a, n) = 1$. $\square$

**Examples:**

- $(\mathbb{Z}/p\mathbb{Z})^\times = \{\bar{1}, \bar{2}, \ldots, \overline{p-1}\}$ for a prime $p$ (all nonzero residues are coprime to $p$). This group has order $p - 1$.

- $|(\mathbb{Z}/p^e\mathbb{Z})^\times| = p^e - p^{e-1} = p^{e-1}(p-1)$. The non-units are exactly the multiples of $p$: $\bar{p}, \overline{2p}, \ldots, \overline{p^{e-1} \cdot p}$, giving $p^{e-1}$ non-units and $p^e - p^{e-1}$ units.

## 7. A Computation with Modular Arithmetic

**Problem.** Find the last two digits of $2^{1000}$.

**Solution.** We need $2^{1000} \pmod{100}$.

```math
2^{10} = 1024 \equiv 24 \pmod{100}
```
```math
2^{20} = (2^{10})^2 \equiv 24^2 = 576 \equiv 76 \pmod{100}
```
```math
76^2 = 5776 \equiv 76 \pmod{100}
```

So $76^k \equiv 76 \pmod{100}$ for all $k \geq 1$ (by induction). Since $2^{1000} = (2^{20})^{50} \equiv 76^{50} \equiv 76 \pmod{100}$, the last two digits are $\mathbf{76}$.

## 8. Preview: Quotient Groups

The construction of $\mathbb{Z}/n\mathbb{Z}$ is a special case of a general construction. Recall from Lecture 4 that the subgroup $n\mathbb{Z}$ is normal in $\mathbb{Z}$ (since $\mathbb{Z}$ is abelian). The coset space $\mathbb{Z}/n\mathbb{Z}$ inherits a group structure from $\mathbb{Z}$, and the projection $\pi: \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$ is a surjective homomorphism with kernel $n\mathbb{Z}$.

**General question:** Given a normal subgroup $H \trianglelefteq G$, can we always make the set of cosets $G/H$ into a group? The answer is **yes**, and this is the content of the next lecture.

The key point is that normality is exactly what ensures the multiplication law on cosets is **well-defined**:

```math
(aH)(bH) \stackrel{?}{=} (ab)H.
```

For this to be independent of the choice of coset representative, we need $H$ to be normal. This will be established rigorously in Lecture 7.
